# Tugas  

* Tugas dikerjakan secara berkelompok  
* Setiap kelompok bebas memilih salah satu dari dataset yang ada direpositori di atas ataupun menggunakan dataset primer/sekunder lainnya. Tidak boleh ada 2 kelompok yang menggunakan dataset sama  
* Setiap kelompok diberikan kebebasan untuk memilih dan mendeskripsikan masalah yang diusulkan untuk diselesaikan melalui sebuah model   
* Berdasarkan model yang dibangun, usulkan prototype sistem untuk dikembangkan/embed yang menjawab kebutuhan industri/permasalahan yang ada  
* Lakukan tahapan-tahapan sebagai berikut (**sesuai pada tahapan model yang dipilih**):  
  * Memahami Proses Bisnis (*bussiness understanding*) dan mendeskripsikan masalah yang akan dipecahkan.  
  * Mehamami Dataset (*data understanding*)  
  * Mempersiapkan Data (*data preparation*)  
  * Mengusulkan model yang akan digunakan (*model development*).  
  * Evaluasi model  
  * Deploy prototype model ke vercel/streamlit  
* Buatlah dokumen terkait dengan pengembangan model tersebut, dan kumpulkan hasilnya yang berupa:  
  * Laporan dalam Format MS Word.  
  * File Presentasi (PPT) dalam format .pdf  
  * File Python dalam format .ipynb.  
* Kumpulkan hasilnya melalui FLearn paling lambat 30 November 23.00 WIB. Format penamaan file NIM\_KEL\_DS Contoh: 682020001\_1\_DS
